# Task 2 – Exploratory Data Analysis (EDA)

## Project Objective
Analyze the dataset to understand patterns, trends, distributions, and identify outliers using descriptive statistics.

## Analysis Performed
- Calculated Count, Mean, and Median for numerical columns.
- Performed outlier analysis using the IQR method.
- Identified 8 outliers in TotalPrice.
- Analyzed yearly sales trends using TotalPrice.
- Summarized key observations from the analysis.

## Key Findings
- Average TotalPrice: 1053.9683
- 8 TotalPrice outliers were identified using the IQR method.
- Sales were highest in 2023 and decreased in 2024 and 2025.

## Dataset
- Total records: 1,200
- Numerical columns analyzed: Quantity, UnitPrice, ItemsInCart, TotalPrice

- Microsoft Excel
